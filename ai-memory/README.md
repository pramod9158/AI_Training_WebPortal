# Waynautic Academy — AI Memory System

Welcome to the AI Memory system for **Waynautic Academy**. This folder serves as the living, persistent source of truth for the codebase, architecture, database schemas, development decisions, and active task status. It is designed so that any developer or AI assistant can immediately gain deep context and resume work with zero onboarding delay.

When joining this project or beginning a new development session, read the documentation files in the following sequence:

## Maintenance Guidelines
- **Always update `CURRENT_STATE.md`** whenever a feature is completed, modified, or a known issue is resolved.
- **Log non-trivial decisions in `DECISIONS.md`** before or immediately after making architectural shifts.
- **Create a session log in `sessions/YYYY-MM-DD.md`** at the conclusion of every working session using [TEMPLATE.md](file:///c:/Users/User/OneDrive/Documents/ai%20training/ai%20training%20web%20portal/ai-memory/sessions/TEMPLATE.md).
